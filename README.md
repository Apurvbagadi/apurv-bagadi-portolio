# Apurv Bagadi — Personal Portfolio

Personal portfolio website for Apurv Satish Bagadi.

## Files
- `index.html` — portfolio website
- `Apurv_Bagadi_ATS_Resume.pdf` — resume linked from the website

## GitHub Pages
1. Open the repository **Settings**.
2. Go to **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select `main` and `/ (root)`.
5. Save.

The portfolio will then be available through the GitHub Pages URL shown by GitHub.
